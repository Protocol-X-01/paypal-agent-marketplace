## Limits

- Prepared locally; no publication, upload, submission edit or deployment is performed.
- This is not an official PayPal/Venmo service. No connected wallet, live customer/staff reporting, real payment, purchase, trade or production security capability is established.
- Market data and AI commentary are historical references; neither represents PayPal execution pricing, guaranteed accuracy or personal financial advice.
- The source tree is uncommitted. The included captures are development previews and do not prove the current code builds or is deployed.
- The new local homepage visual seen on 7 November is not an included capture. The included homepage image is explicitly historical from 6 November.
- Native visual acceptance covers three Markets captures from one Xiaomi Android 15 debug-app session: overview, chart with indicators, and chart after refresh. The later refreshed JavaScript was served live over Metro and is not baked into a standalone release APK. Other app sections, iOS/tablet, release packaging and hosted behavior remain unverified by these captures.
- CoinGecko overview quote retrieval was 09:00:59.060 UTC with provider update 08:59:57.000 UTC. At capture, the line chart retrieval was 08:48:12.523 UTC and the 7-day sparkline retrieval was 08:01:50.628 UTC. These timestamps show different freshness; none proves 100% accuracy or a PayPal/Venmo execution price.
- The refreshed screen used an existing debug APK with updated JavaScript served live over Metro; it does not prove a rebuilt or standalone release app. A repeated overview retrieval timestamp triggered a warning and does not establish an upstream refresh or price-accuracy guarantee.
- The new dark-mode capture covers only the Markets overview in one Xiaomi Android 15 debug session. Metro served the updated JavaScript; the exact bundle hash is not recorded and the APK is not a standalone release build. The web, Shop, Portfolio and Account screens were not recaptured in dark mode for this edition.
